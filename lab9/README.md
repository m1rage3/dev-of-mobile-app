# Лабораторная работа 9

`Lab9_Map` — карта Яндекса (MapKit lite 4.45.0): 6 предзаданных точек Новосибирска, карточка по клику,
добавление метки долгим нажатием, сохранение своих меток в Room.

## API-ключ

Ключ в репозиторий не попадает. Перед сборкой добавьте строку в `Lab9_Map/local.properties`:

```
MAPKIT_API_KEY=ваш_ключ
```

Ключ выдают в Кабинете разработчика Яндекса (сервис «MapKit — мобильный SDK»), активируется около 15 минут.
